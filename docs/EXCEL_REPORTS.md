# Excel-отчёты

Кнопка «Экспорт Excel» доступна во всех действующих системах. В журнале действий она выгружает сам журнал, а не данные системы, из которой он открыт. Данные берутся с сервера с правами текущего профиля; при ошибке загрузки неполный отчёт не скачивается.

| Система | Листы отчёта |
| --- | --- |
| Электронный журнал | Активные заявки, история ремонтов, решения, неудалённые заметки ремонта |
| Парк | Список машин и все листы электронного журнала |
| Информаторы | Оборудование по бортам, состояние и заметки |
| Контроль навигации | Сводка и результаты по дням за выбранный период |
| БСО | Полные и короткие номера, доступная история замен |
| Смены ЗР | График на выбранный период и сохранённые параметры расписания; время московское |
| Склад | Текущие остатки, заводские номера, потребности участков, сводка движения, движения, закупки |
| Роли и права | Профили, разрешения, системы, участок и смена; без паролей |
| Журнал действий | Последние 300 действий, как в интерфейсе; без содержимого удалённых заметок |

В складском разделе «Журнал и статистика» период, участок, смена и борт ограничивают листы движения и сводки. Участок, смена и борт также ограничивают потребности. Их даты создания не ограничиваются периодом движения: это отмечено в подзаголовке листа. Остатки, заводские номера и закупки показывают текущее состояние, а не остатки на конец выбранного периода. В остальных вкладках склада выгружаются все доступные движения.

Отчёты журнала, парка и информаторов содержат все доступные профилю записи, независимо от экранного поиска. История замен БСО ограничивается выдаваемыми сервером последними 500 записями. ПТО и техническое обслуживание остаются разделами в разработке.

Числовые количества сохраняются числами, номера и пользовательский текст — строками. Удалённые заметки не включаются в отчёт; запись о факте удаления остаётся в решениях. Заголовки закреплены, включены фильтры, высота строк учитывает переносы текста.
