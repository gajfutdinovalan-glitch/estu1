ЕСТУ — переносимая тестовая сборка

Для разработчиков: карта модулей и прохождение запроса описаны в docs\ARCHITECTURE.md.

Для запуска:
1. Скопируйте всю папку на компьютер с Windows 10 или 11.
2. Не запускайте файлы прямо из ZIP-архива. Сначала распакуйте всю папку.
3. Дважды нажмите ESTU START.cmd.
4. ЕСТУ откроется в браузере на http://127.0.0.1:8080/ или на ближайшем свободном порту.
   Ярлыки на рабочем столе создаются, только если Windows разрешает запись.
5. При ошибке окно команды останется открытым. Подробности ошибки старта сервера
   также сохраняются в server\data\portable-startup.log.

Дополнительные программы, SQL Server, Docker и Visual Studio не требуются.
Не перемещайте отдельные файлы из папки: переносить нужно папку целиком.

Остановка:
- ESTU STOP.cmd останавливает локальный сервер и обработчик почты.

Выгрузка данных:
- администратор может нажать «Выгрузить тестовые данные» в журнале;
- или запустить ESTU EXPORT.cmd / ярлык ESTU Export;
- готовый ZIP сохраняется в папке Exports.

Резервные копии:
- база находится в server\data\estu-portable.sqlite;
- ежедневные копии создаются в backups\portable;
- сохраняются последние 35 ежедневных копий.

Работа без интернета:
- журнал, парк, БСО и остальные локальные разделы продолжают работать;
- Яндекс Формы и почта синхронизируются после восстановления интернета.

Важно:
- сервер доступен только на этом компьютере через localhost;
- пароль почты после переноса на другой компьютер нужно ввести повторно;
- не удаляйте папки server\data, backups и Exports.
